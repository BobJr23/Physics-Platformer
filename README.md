# Physics-Platformer

This is a physics-based platformer game using pygame and pymunk. 

**Controls**
WASD and Arrow Keys

**Objective**

Get to the hidden tile together, or just mess around and do parkour :)

Brown tiles are buttons, which move obstacles and can be pressed by objects or players.

Red player can't touch blue, and vice-versa

Green is poison, which kills both players

Press 1 and 2 to go between levels
